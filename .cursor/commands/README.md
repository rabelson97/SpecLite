# Cursor Commands

Slash commands are symlinked to the markdown workflows, actions, and scripts in this repo.

## Workflow commands
- `/0-new-run`
- `/1-requirements`
- `/2-research`
- `/3-plan`
- `/4-implement`
- `/5-validate`
- `/version-control`

## Action commands
- `/0-setup`
- `/0-cleanup-cache`
- `/manage-workflow`
- `/save-learnings`

## Script commands
- `/8-index-codebase`
- `/9-run-workers`

## How to use
Open any command file under `.cursor/commands/` and run the command block inside.
