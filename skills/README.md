# SpecLite Skills

SpecLite borrows the best idea from specialist agent kits: reusable knowledge modules.

These skills are deliberately small and framework-oriented. They support workflows instead of overshadowing them.

## Included skills

- `requirements-elicitation.md`
- `repo-research.md`
- `task-decomposition.md`
- `validation-strategy.md`
- `release-hygiene.md`

## Philosophy

- Skills encode repeatable know-how.
- Workflows decide when to apply them.
- Runs remain the source of truth.
