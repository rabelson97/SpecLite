## Suggested launch post

### Short version

Built **SpecLite**: an artifact-first AI development workflow for **Codex, Cursor, and Kiro**.

It combines spec-driven phases (`requirements -> research -> plan -> implementation -> validation`) with a smoother front door (`brainstorm`, `debug`, `enhance`, `orchestrate`, `status`).

The goal: keep the ergonomics of agent kits, but make the work more traceable, reusable, and reviewable.

### Longer version

I wanted a workflow that felt lighter than heavyweight spec systems, but more disciplined than a pile of prompts.

So I built **SpecLite** — an artifact-first AI development workflow framework with:

- run directories for every initiative
- canonical SDLC phases
- intent-based workflow entry points
- reusable skills and lightweight specialist overlays
- integrations for Codex, Cursor, and Kiro

If you care about spec-driven development, AI coding workflows, or making agent-assisted work easier to review and share, this might be useful.
