# SpecLite Agents

SpecLite now includes a small, practical agent model designed to improve routing and ergonomics without sacrificing traceable artifacts.

## Design principles

- **Few agents, clear jobs**: only keep roles that materially improve output quality.
- **Artifact-first**: agents do not replace phase outputs; they sharpen them.
- **Composable**: one workflow can apply multiple agent lenses.
- **Portable**: agents are plain markdown/docs so they can be adapted across tools.

## Included agents

- `product-manager.md`
- `research-lead.md`
- `technical-lead.md`
- `implementation-engineer.md`
- `validator.md`
- `release-assistant.md`

These are reference personas for routing, workflow authoring, and future editor integrations.
