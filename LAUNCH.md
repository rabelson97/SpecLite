# SpecLite Launch Kit

## One-line positioning

SpecLite is an artifact-first AI workflow framework that combines workflows, docs, rules, and runs so software teams can ship with more speed and less chaos.

## Short post

Built **SpecLite** — an artifact-first AI workflow framework for shipping software with **Codex, Cursor, Claude Code, and Kiro**.

It combines:
- front-door workflows like `brainstorm`, `debug`, `enhance`, and `workflow`
- project-local `.speclite/` docs and rules
- run artifacts for research, planning, validation, and delivery

The goal is simple: keep AI workflows fast, but make them inspectable, reusable, and easier to trust.

## Slightly longer post

Most AI coding workflows are great at momentum and bad at memory.

So I built **SpecLite** — a spec-driven framework that combines:
- **workflows** for execution
- **docs** for project knowledge
- **rules** for codebase behavior
- **runs** for artifact-first traceability

It now supports **Codex, Cursor, Claude Code, and Kiro**, and each project can define its own local framework layer in `.speclite/`.
